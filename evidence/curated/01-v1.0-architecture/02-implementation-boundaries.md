# 模块验收、技术价值与边界

| 模块 | 实际机制 | 边界 |
|---|---|---|
| Agent Runtime | 版本化角色、Provider、工具白名单、异步推理、超时/取消/调用计数 | 注册表与认领仍单进程，非分布式运行时 |
| TaskPlanner | 模型生成计划，Schema/引用/DAG/节点/工具/验证白名单校验，用户版本确认 | 最大3节点，动态推理效果不保证；模板/Mock明确标识 |
| WorkflowEngine | 顺序、并行、条件、受限循环、子流程，输入产物映射、状态和SQLite快照 | 普通DAG拒环，不提供崩溃自动续跑 |
| CAAS | 技能/权限过滤，能力、可靠性、负载、成本、延迟评分，原子认领 | 无充分统计显著优势证据，不是强化学习调度 |
| VerifierEngine | JSON Schema、规则、数值及可信外部回调，产物版本绑定 | 通过配置规则不代表开放领域语义正确 |
| FeedbackEngine | 错误分类、证据引用、恢复策略 | 不修改规则使任务过关，不把所有失败归因能力 |
| SelfLoop | 新attempt/产物、原验证反馈传递，重试/重新分配等有限恢复 | 根预算/时限约束；不保证真实修复成功 |
| DeepSeek | 兼容HTTP、配置白名单、安全凭据交接、限额和用量 | 不提供账单硬预算，未知用量保持未知 |
| 知识增强 | TXT/MD/PDF/DOCX、中文字符索引FTS5/BM25、限定库检索、引用验证 | 非向量语义检索；无OCR，多租户权限未实现 |
| 普通工作台 | 需求→计划→确认→真实引擎→成果、复制导出、审计 | 可信本机单用户，不能直接公网运营 |
| 专业工作台 | Agent、模型、VueFlow编排、监控、策略与尝试详情 | 非任意代码生成执行平台 |
| 比赛回放 | 已有真实记录及全部离线实验，只读因果链 | 历史回放不是当前实时付费推理 |

可陈述的技术价值：将候选筛选、可解释评分、独立验证、版本化证据、共享预算和受限反馈串成同一执行体系；将专业编排能力封装为可确认的普通用户计划；把知识来源和具体尝试绑定，防止伪造引用或把空检索标为增强成功。属于系统机制设计和集成成果，不声称发明通用最优算法或已有生产规模验证。

安全边界：无不受限Shell/任意代码工具；知识内容作为不可信数据，不能扩大工具或库范围。但没有完整代码沙箱、强租户鉴权、生产出口隔离或恶意PDF的独立CPU/内存沙箱。文档来源存在不等于论证正确；费用估算不等于实际账单。开源依赖许可、官方提交细则、最终截图和录屏仍需负责人核查。
